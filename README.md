# Deepthi P S | Portfolio

Personal portfolio website of Deepthi P S, a full stack web developer based in Bengaluru, Karnataka.

It covers my skills, work experience at Excelr Pvt Ltd, and my Employee Management System project (React.js, Node.js, Express.js, MySQL, JWT, Docker, Nginx).

## Built with

- HTML5
- CSS3 (light and dark theme, responsive layout)
- JavaScript (ES6+)
- React 18 (loaded from a CDN, no build step needed)

## Run it locally

1. Download or clone this repository.
2. Keep `index.html`, `styles.css` and `app.js` in the same folder.
3. Open `index.html` in your browser.

An internet connection is needed because React and the fonts load from a CDN.

## Project structure

```
.
├── index.html   # page shell and script tags
├── styles.css   # all styles and theme colors
├── app.js       # React components and portfolio content
└── README.md
```

To change any text (skills, experience, project details), edit the data at the top of `app.js`.
